# RSS feeds

`@skyscribe-sdk/core` exports `generateFeed`, which takes a fetched `StandardPublication` and returns a complete RSS 2.0 XML string. Call it from a server-side route handler and return the result as the response.

## Basic usage

`generateFeed` needs a `baseUrl`: your website's origin. Pass `feedUrl` too (the feed's own URL), so the feed identifies itself to readers:

```ts
import { fetchPublication, generateFeed } from '@skyscribe-sdk/core';

const publication = await fetchPublication('alice.bsky.social', 'https://alice.bsky.social');
const xml = generateFeed(publication, {
  baseUrl: 'https://alice.example.com',
  feedUrl: 'https://alice.example.com/feed.xml',
});
```

The options:

| Option | Default | Meaning |
| ------ | ------- | ------- |
| `baseUrl` | (required) | Your website's origin, used to build each Document's link |
| `feedUrl` | none | The feed's own URL, added as an `atom:link rel="self"` |
| `language` | `"en"` | The channel's `<language>` |
| `limit` | all | Include at most this many Documents |

## Wiring into your framework

<Tabs>
  <Tab label="React Router v7/v8">
    ```ts
    // app/routes/feed.ts
    import { fetchPublication, generateFeed } from '@skyscribe-sdk/core';

    export async function loader({ request }: { request: Request }) {
      const origin = new URL(request.url).origin;
      const publication = await fetchPublication('alice.bsky.social', 'https://alice.bsky.social', request.signal);
      const xml = generateFeed(publication, {
        baseUrl: origin,
        feedUrl: `${origin}/feed.xml`,
      });
      return new Response(xml, {
        headers: { 'Content-Type': 'application/rss+xml; charset=utf-8' },
      });
    }
    ```

## What gets included

`generateFeed` includes the Documents in the Publication's Categories, which are its published Documents. Items come out in Category order, then in each Category's Document order, not sorted by date, and `limit` applies to that order. To get newest first, sort the Categories' Documents by `publishedAt` before calling `generateFeed`.

Each item contains:
- `<title>`: the Document's title
- `<description>`: the Document's description (empty if none)
- `<link>`: `{baseUrl}/{basePath}/{category slug}/{document slug}`
- `<pubDate>`: `publishedAt`, or `createdAt` if the Document has no publish date
- `<guid>`: the same URL as `<link>`

## Feed auto-discovery

Add a `<link>` tag in your HTML `<head>` so feed readers can discover the feed automatically:

```html
<link
  rel="alternate"
  type="application/rss+xml"
  title="My Blog"
  href="/feed.xml"
/>
```

`publicationMeta` and the other meta helpers don't add this tag, so add it in your root layout.
