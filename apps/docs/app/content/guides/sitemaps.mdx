# Sitemaps

`@skyscribe-sdk/core` exports `getSitemapEntries`, which takes a fetched `StandardPublication` and returns an array of `{ url, lastmod? }` objects. You build the XML from them yourself, so you keep full control of the output and can merge in your own pages.

## Basic usage

```ts
import { fetchPublication, getSitemapEntries } from '@skyscribe-sdk/core';

const publication = await fetchPublication('alice.bsky.social', 'https://alice.bsky.social');
const entries = getSitemapEntries(publication, { baseUrl: 'https://alice.example.com' });

// entries is: Array<{ url: string; lastmod?: string }>
```

Two kinds of Document are left out: one whose canonical URL is another website's (an imported Document whose author kept the original as canonical), and one whose author turned on **noindex** in its SEO Settings. Both still appear on your site and in your feed: they just aren't offered to search engines.

## Wiring into your framework

<Tabs>
  <Tab label="React Router v7/v8">
    ```ts
    // app/routes/sitemap.ts
    import { fetchPublication, getSitemapEntries } from '@skyscribe-sdk/core';

    export async function loader({ request }: { request: Request }) {
      const origin = new URL(request.url).origin;
      const publication = await fetchPublication('alice.bsky.social', 'https://alice.bsky.social', request.signal);
      const entries = getSitemapEntries(publication, { baseUrl: origin });

      const xml = [
        '<?xml version="1.0" encoding="UTF-8"?>',
        '<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">',
        ...entries.map(
          (e) =>
            `<url><loc>${e.url}</loc>${e.lastmod ? `<lastmod>${e.lastmod}</lastmod>` : ''}</url>`
        ),
        '</urlset>',
      ].join('');

      return new Response(xml, {
        headers: { 'Content-Type': 'application/xml; charset=utf-8' },
      });
    }
    ```

## Adding your own pages

`getSitemapEntries` only knows about the Publication's Documents. Append any other pages your website has, such as an about page:

```ts
const entries = getSitemapEntries(publication, { baseUrl: origin });

const allEntries = [
  ...entries,
  { url: `${origin}/about` },
];
```

## What gets included

`getSitemapEntries` returns, in order:
- the home page: `baseUrl`
- the base path root, if the Publication has a `basePath`: `{baseUrl}/{basePath}`
- each Category's page: `{baseUrl}/{basePath}/{category slug}`
- each published Document: `{baseUrl}/{basePath}/{category slug}/{document slug}`

Document entries have a `lastmod` date (`YYYY-MM-DD`) taken from the Document's `updatedAt`, when it's set. Drafts aren't in the Publication record, so they're never included.

<Callout>
  The URLs follow the standard layout. If your website uses different paths for Category pages, or doesn't have them, filter or rewrite the entries before building the XML.
</Callout>
