# Sitemaps

`@skyscribe-sdk/core` exports `getSitemapEntries`, which takes a fetched `Site` and returns an array of `{ url, lastmod? }` objects. You build the XML from them yourself, so you keep full control of the output and can merge in your own pages.

## Basic usage

```ts
import { fetchSite, getSitemapEntries } from '@skyscribe-sdk/core';

const site = await fetchSite('alice.bsky.social', 'https://alice.bsky.social');
const entries = getSitemapEntries(site, { baseUrl: 'https://alice.example.com' });

// entries is: Array<{ url: string; lastmod?: string }>
```

Two kinds of article are left out: one whose canonical URL is another website's (an imported article whose author kept the original as canonical), and one whose author turned on **noindex** in its SEO Settings. Both still appear on your site and in your feed: they just aren't offered to search engines.

## Wiring into your framework

<Tabs>
  <Tab label="React Router v7/v8">
    ```ts
    // app/routes/sitemap.ts
    import { fetchSite, getSitemapEntries } from '@skyscribe-sdk/core';

    export async function loader({ request }: { request: Request }) {
      const origin = new URL(request.url).origin;
      const site = await fetchSite('alice.bsky.social', 'https://alice.bsky.social', request.signal);
      const entries = getSitemapEntries(site, { baseUrl: origin });

      const xml = [
        '<?xml version="1.0" encoding="UTF-8"?>',
        '<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">',
        ...entries.map(
          (e) =>
            `<url><loc>${e.url}</loc>${e.lastmod ? `<lastmod>${e.lastmod}</lastmod>` : ''}</url>`
        ),
        '</urlset>',
      ].join('');

      return new Response(xml, {
        headers: { 'Content-Type': 'application/xml; charset=utf-8' },
      });
    }
    ```

## Adding your own pages

`getSitemapEntries` only knows about the Site's content. Append any other pages your website has, such as an about page:

```ts
const entries = getSitemapEntries(site, { baseUrl: origin });

const allEntries = [
  ...entries,
  { url: `${origin}/about` },
];
```

## What gets included

`getSitemapEntries` returns, in order:
- the home page: `baseUrl`
- the path-prefix root, if the Site has a `urlPrefix`: `{baseUrl}/{urlPrefix}`
- each Group's page: `{baseUrl}/{urlPrefix}/{group slug}`
- each published article: `{baseUrl}/{urlPrefix}/{group slug}/{article slug}`

Article entries have a `lastmod` date (`YYYY-MM-DD`) taken from the article's `updatedAt`, when it's set. Drafts aren't in the Site record, so they're never included.

<Callout>
  The URLs follow the standard layout. If your website uses different paths for Group pages, or doesn't have them, filter or rewrite the entries before building the XML.
</Callout>
