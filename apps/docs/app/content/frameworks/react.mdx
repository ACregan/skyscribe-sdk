# React

`@skyscribe-sdk/react` provides `useSite`, `useArticleBySlug` and `useArticle` hooks for React SPAs and client-rendered components. Each hook manages loading state, error state and request cancellation for you.

<Callout>
  For **React Router v7/v8 framework (server) mode**, use [`@skyscribe-sdk/react-router-framework`](/frameworks/react-router) instead. For the **Next.js App Router**, use [`@skyscribe-sdk/next`](/frameworks/next).
</Callout>

## Install

```bash
npm install @skyscribe-sdk/react
```

Requires React 18 or later.

## `useSite`

```tsx
import { useSite } from '@skyscribe-sdk/react';

function BlogIndex() {
  const { site, loading, error } = useSite('alice.bsky.social', 'https://alice.bsky.social');

  if (loading) return <p>Loading…</p>;
  if (error)   return <p>Error: {error.message}</p>;
  if (!site)   return null;

  return (
    <main>
      <h1>{site.title}</h1>
      {site.groups.map((group) => (
        <section key={group.slug}>
          <h2>{group.title}</h2>
          <ul>
            {group.articles.map((article) => (
              <li key={article.uri}>
                <a href={`/${group.slug}/${article.slug}`}>{article.title}</a>
              </li>
            ))}
          </ul>
        </section>
      ))}
    </main>
  );
}
```

## `useArticleBySlug`

Article pages usually have the article's slug from the URL (`/essays/my-first-post`). `useArticleBySlug` looks it up in the Site and returns the article with its AT URI:

```tsx
import { useArticleBySlug, ScribeContent } from '@skyscribe-sdk/react';

function ArticlePage({ slug }: { slug: string }) {
  const { article, uri, loading, error } = useArticleBySlug(
    'alice.bsky.social',
    'https://alice.bsky.social',
    slug,
  );

  if (loading) return <p>Loading…</p>;
  if (error)   return <p>Error: {error.message}</p>;
  if (!article) return null;

  return (
    <article>
      <h1>{article.title}</h1>
      {article.description && <p>{article.description}</p>}
      <ScribeContent html={article.content} />
    </article>
  );
}
```

`uri` is what [`@skyscribe-sdk/social`](/guides/social)'s buttons need as `documentUri`. If no published article has that slug, `error` is a `NotFoundError`.

## `useArticle`

If you already have an `ArticleRef` (for example while listing a Site's articles), `useArticle` skips the Site lookup. It takes the article's account and **record key (rkey)**, both found in `ArticleRef.uri` (`at://{did}/site.standard.document/{rkey}`). Take the account from there rather than assuming the site owner's: an article credited to a contributor can live in their account.

```tsx
import { useArticle } from '@skyscribe-sdk/react';
import { slugFromUri } from '@skyscribe-sdk/core';
import type { ArticleRef } from '@skyscribe-sdk/react';

function ArticlePreview({ articleRef }: { articleRef: ArticleRef }) {
  const did = articleRef.uri.split('/')[2];
  const { article } = useArticle(did, slugFromUri(articleRef.uri));
  // …
}
```

Don't pass a slug to `useArticle`: articles published with current tooling have opaque rkeys, so a slug only finds very old articles.

All three hooks re-fetch when their arguments change, and abort the in-flight request when the component unmounts.

`<ScribeContent>` renders article HTML inside a `scribe-content` wrapper, ready for [`@skyscribe-sdk/styles`](/frameworks/styles). If you render articles from accounts you don't control, sanitise the HTML first (see [Rendering the HTML](/quickstart#3-fetch-an-article)).

## Site Analytics

Show the Publication's owner visit figures on its Insights tab in SkyScribe (free, cookie-free):

```tsx
// Once, in your root layout
import { SiteAnalytics } from '@skyscribe-sdk/react';

<SiteAnalytics />
```

Figures only appear once your site serves the Publication verification file. See the [Site Analytics guide](/guides/site-analytics) for that, privacy, and CSP.

## TypeScript types

The main types from `@skyscribe-sdk/core` are re-exported, so you rarely need to import from both packages:

```ts
import type { Site, Article, ArticleRef, SiteGroup, ArticleResult } from '@skyscribe-sdk/react';
```
