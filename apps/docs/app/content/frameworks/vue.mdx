# Vue

`@skyscribe-sdk/vue` provides `useScribeSite`, `useScribeArticleBySlug` and `useScribeArticle` composables for Vue 3. Each returns reactive refs for `site` / `article`, `loading` and `error`, and aborts the in-flight request when the component unmounts.

<Callout>
  For **Nuxt 3**, use [`@skyscribe-sdk/nuxt`](/frameworks/nuxt) instead: its composables use `useAsyncData`, so content is fetched during server rendering, and they're auto-imported.
</Callout>

## Install

```bash
npm install @skyscribe-sdk/vue
```

Requires Vue 3 or later.

## `useScribeSite`

```vue
<script setup lang="ts">
import { useScribeSite } from '@skyscribe-sdk/vue';

const { site, loading, error } = useScribeSite('alice.bsky.social', 'https://alice.bsky.social');
</script>

<template>
  <p v-if="loading">Loading…</p>
  <p v-else-if="error">Error: {{ error.message }}</p>
  <main v-else-if="site">
    <h1>{{ site.title }}</h1>
    <section v-for="group in site.groups" :key="group.slug">
      <h2>{{ group.title }}</h2>
      <ul>
        <li v-for="article in group.articles" :key="article.uri">
          <a :href="`/${group.slug}/${article.slug}`">{{ article.title }}</a>
        </li>
      </ul>
    </section>
  </main>
</template>
```

## `useScribeArticleBySlug`

Article pages usually have the article's slug from the URL. `useScribeArticleBySlug` looks it up in the Site and returns the article with its AT URI:

```vue
<script setup lang="ts">
import { useScribeArticleBySlug } from '@skyscribe-sdk/vue';

const props = defineProps<{ slug: string }>();
const { article, uri, loading, error } = useScribeArticleBySlug(
  'alice.bsky.social',
  'https://alice.bsky.social',
  props.slug,
);
</script>

<template>
  <p v-if="loading">Loading…</p>
  <p v-else-if="error">Error: {{ error.message }}</p>
  <article v-else-if="article">
    <h1>{{ article.title }}</h1>
    <p v-if="article.description">{{ article.description }}</p>
    <div class="scribe-content" v-html="article.content" />
  </article>
</template>
```

If you render articles from accounts you don't control, sanitise `content` before passing it to `v-html` (see [Rendering the HTML](/quickstart#3-fetch-an-article)).

## `useScribeArticle`

If you already have an `ArticleRef`, `useScribeArticle` skips the Site lookup. It takes the article's account and **record key (rkey)**, both found in `ArticleRef.uri` (`at://{did}/site.standard.document/{rkey}`). Take the account from there: an article credited to a contributor can live in their account.

```ts
import { useScribeArticle } from '@skyscribe-sdk/vue';
import { slugFromUri } from '@skyscribe-sdk/core';

const did = articleRef.uri.split('/')[2];
const { article } = useScribeArticle(did, slugFromUri(articleRef.uri));
```

Don't pass a slug to `useScribeArticle`: articles published with current tooling have opaque rkeys, so a slug only finds very old articles.

## Just the AT URI: `useScribePublicationUri` / `useScribeDocumentUri`

`@skyscribe-sdk/social`'s buttons are React components, so you can't use them in a Vue template. If you're building your own like or subscribe UI, `useScribePublicationUri` and `useScribeDocumentUri` resolve just the AT URI you need. `useScribeDocumentUri` takes the article's **slug**:

```vue
<script setup lang="ts">
import { useScribeDocumentUri } from '@skyscribe-sdk/vue';

const props = defineProps<{ author: string; publicationUrl: string; slug: string }>();
const { uri } = useScribeDocumentUri(props.author, props.publicationUrl, props.slug);
</script>

<template>
  <p v-if="uri">AT URI: {{ uri }}</p>
</template>
```

## Site Analytics

Show the Publication's owner visit figures on its Insights tab in SkyScribe (free, cookie-free):

```vue
<!-- Once, in App.vue -->
<script setup lang="ts">
import { SiteAnalytics } from '@skyscribe-sdk/vue';
</script>

<template>
  <RouterView />
  <SiteAnalytics />
</template>
```

Figures only appear once your site serves the Publication verification file. See the [Site Analytics guide](/guides/site-analytics) for that, privacy, and CSP.

## TypeScript types

The main types from `@skyscribe-sdk/core` are re-exported:

```ts
import type { Site, Article, ArticleRef, SiteGroup } from '@skyscribe-sdk/vue';
```
