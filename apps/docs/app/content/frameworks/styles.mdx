# Styles

`@skyscribe-sdk/styles` is a plain CSS package: no JavaScript, no build step, no framework dependency. It styles Document content (code blocks, blockquotes, lists, checklists, images) inside any element with the `scribe-content` class. Install it alongside whichever framework adapter you're using:

```bash
npm install @skyscribe-sdk/styles
```

## React

Import the stylesheet once, then use `@skyscribe-sdk/react`'s `<ScribeContent>` component, which applies the `scribe-content` class for you:

```tsx
import { ScribeContent } from '@skyscribe-sdk/react';
import '@skyscribe-sdk/styles';

<ScribeContent html={document.content} />
```

## Vue

```vue
<script setup lang="ts">
import '@skyscribe-sdk/styles';
</script>

<template>
  <div class="scribe-content" v-html="document.content" />
</template>
```

## Angular

Add the stylesheet to your global styles in `angular.json`:

```json
"styles": [
  "src/styles.css",
  "node_modules/@skyscribe-sdk/styles/src/index.css"
]
```

```html
<div class="scribe-content" [innerHTML]="doc.content"></div>
```

## Next.js

Import once, typically in your root layout:

```tsx
// app/layout.tsx
import '@skyscribe-sdk/styles';
```

In server components, render the HTML into an element with the `scribe-content` class:

```tsx
<div className="scribe-content" dangerouslySetInnerHTML={{ __html: document.content }} />
```

(`@skyscribe-sdk/react`'s package entry also contains client-side hooks, so keep its `<ScribeContent>` for client components.)

## Plain HTML / any other framework

Import the stylesheet, and apply the `scribe-content` class to whichever element you render `document.content` into:

```html
<link rel="stylesheet" href="/node_modules/@skyscribe-sdk/styles/src/index.css" />
<!-- or, if bundling: import "@skyscribe-sdk/styles"; -->

<div class="scribe-content"><!-- document.content HTML here --></div>
```
